# No-blank metabolite annotation Streamlit app

Upload app.py and requirements.txt to GitHub and deploy on Streamlit Community Cloud.

This version searches PubChem, KEGG, ChEBI/OLS, ClassyFire, PubMed and Europe PMC. It also fills missing fields with conservative closest-compartment and exogenous/unclassified fallback rules.

Recommended test: Cysteine + preeclampsia.
